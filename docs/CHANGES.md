# 相对上游的变化与限制

上游：https://github.com/laq12345/paperman ，比较基线 a8df113。

## 已有下载改进

- PDF 来源顺序为 arXiv、PMC、Sci-Hub、出版社；两轮失败后增加标题查找 arXiv。匹配 DOI 冲突会拒绝，缺少 DOI 时需要标题与作者一致，歧义结果不自动采用。
- Sci-Hub 增加镜像与候选 PDF 链接处理，直连与独立代理尝试，避免修改出版社客户端的网络配置。
- Crossref 保存全文链接和落地页；出版社优先利用元数据，Elsevier 使用真实 PII，不再把 DOI 后缀直接当作 PII；加入 Wiley 10.1002 等处理。
- 网络可显式直连，保留 TLS 校验，增加请求诊断。
- 增加 HTML/XML 发现、正文校验、持久化、报告与导入工具。摘要页或预览不等于全文。

## 本轮可迁移整理

- 安装后的 paperman-bulk 和 paperman-doctor 入口，不依赖源码目录或临时依赖路径。
- PDF 与 HTML/XML 默认共用网络配置，支持自定义配置和数据目录。
- 每 DOI 超时、进程组清理、输出目录锁、每次尝试日志、相对文件路径、PDF 可解析性及 DOI 文本检查。
- 基于每 DOI 最新记录重建汇总，区分保存文件和有 DOI 检查证据的文件，避免沿用旧汇总数字。
- 补充迁移说明、配置样例、测试版本约束与离线 CI；保留上游许可和说明。

## 尚未解决

- 网站访问策略、机构权限、反自动化检查与代理服务稳定性不是代码配置一次就能保证的。镜像和网页结构也会变化。
- 部分出版社模板仍较粗糙；DOI 前缀不是可靠的文章出版商分类依据，分层抽样需结合元数据核查。
- arXiv 标题匹配可能漏掉改题或作者写法不同的版本；目前不能宣称它已显著提高真实样本成功率。
- PDF 文本 DOI 检查是初步核验，扫描件、无 DOI 正文或引文 DOI 都需要人工复核；不保证最终发表版本。
- HTML/XML 和 PDF 两套任务记录尚未统一；浏览器与旧实验脚本已归入 scripts/experimental，仍存在设备/数据集假设。
- 批量入口为 POSIX；没有原生 Windows、分布式队列或多工作进程支持。请求诊断使用进程环境上下文，不能直接改成共享线程并发。
- 本地安装和测试不等于 GitHub CI 已执行；旧 pixi 锁文件尚未更新。未声称跨设备或大规模线上验证全部通过。

历史 100 篇实验曾记录 94 个已保存 PDF，其中来源记录为出版社 19、Sci-Hub 75；这不是全面审计后的 94% 通用成功率，也不能推断 HTML/XML 的成功率。实际数据与日志保留在私有语料目录，不随代码分发。

本轮追加：来源顺序/重试次数参数、结构化阶段日志、元数据出版社字段、中断状态，以及显式代理优先于环境变量的修复。实际测试条件和结果见 ACCEPTANCE.md。
