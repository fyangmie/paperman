## 在线小样本

DOI：10.1007/s10854-024-14066-2，一篇已知 Springer OA 文章。只有一篇，不能外推成功率。

| 项目 | 结果 |
|---|---|
| PDF / HTML 出口 | 两种客户端均直连，出口一致；显示中国电信，未验证校园机构访问 |
| HTML | 下载并通过现有正文校验 |
| XML | 下载并通过现有正文校验 |
| 默认来源顺序的 PDF | 120 秒总时限用尽，停在 Sci-Hub 阶段，尚未到出版社 |
| 真实中断 | 对独立测试批次发送 SIGINT，run.json 记录 interrupted |
| 重试 PDF | 通过 --sources 将 publisher 放在首位，约 22 秒完成；默认顺序未修改 |
| PDF 检查 | 19 页，目标 DOI 文本命中，来源 publisher |
| 目录复制后恢复 | PDF 跳过已有文件且 SHA256 不变；HTML/XML 两项均跳过 |
| 恢复后汇总 | PDF 保存 1、DOI 检查通过 1；HTML/XML 各有一个已保存正文 |

PDF 文本解析出现可选 fontTools 缺失提示；本例仍成功解析并命中 DOI，但这不证明所有字体和扫描件都能准确提取。DOI 命中不代替人工内容核验。

## 连接校园 VPN 后的复测

用户重新连接 VPN 后，PDF 与 HTML 客户端诊断均显示 CERNET（AS4538）出口，且不走配置代理；证明当前运行环境的路由已变化。私有原始记录保存在独立验收目录。

对 10.1002/adma.201404591 使用 --sources publisher --retries 0 单独测试出版社访问：Crossref 200，PMC 编号查询 200，Wiley PDF 请求 403，诊断记录 challenge=true，最终 no_pdf，失败阶段 pdf / publisher。约 3.3 秒结束，不是总时限超时。没有取得 PDF，不能宣称机构订阅访问验收通过，也不能仅据此判断学校无权限。

这次仅核对出版社访问，未将其他渠道成功当作学校认证成功。HTML 客户端的校园出口已核对，但该 Wiley 正文访问未另行验收。
